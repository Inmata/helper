# 群人格选择

机器人提供两个人格：

- 熟人损友：沿用自然接话、适度调侃和认真回答的风格。
- 俏皮损友：活泼、机灵、亲近的年轻女性角色，有自己的喜好和小情绪；被夸会开心，被纠正会承认小尴尬，玩梗时愿意陪对方演一拍，也会好奇、夸奖和关心，轻轻调侃就停。推荐搭配星瞳音色。

所有群友可发 `/人格` 查看当前人格与可选项；管理员发 `/人格 损友` 或 `/人格 俏皮` 切换。完整名称也可用，旧 `/切换人格` 是同义命令。

选择按账号及群保存，重启保留。未选择时沿用熟人损友。切换后，尚未发出的旧人格回复取消，聊天记录、群聊习惯补充和音色保留；补充的归纳、回退与回到基准保留所选人格。

两个人格分别定义互动方式，共用事实、功能和输出格式约束。俏皮人格把群聊习惯和旧回复作为理解话题的资料，当前口吻按所选人格生成，不自动沿用群友口头禅或旧人格的顶嘴方式。

所选人格用于文字、语音聊天、主动发言及模型生成的总结；事实、来源和功能要求优先。`/语音 原文` 直接照念原文。

提示词位于 `wxbot_framework/conversation/personality.py`，修改共享模块后应重启机器人。
