# 艾特机器人对话

微信真艾特、手打匹配机器人的称呼、引用机器人消息都能触发回复；只艾特别人不会触发。

配置的维护者可在群内用 `/冷处理 @群友 30m` 临时改变机器人对指定成员的艾特回复。模型接着对方刚说的话回一句，之后至少隔 10 分钟才再回，中间的艾特直接跳过。也可用成员编号或微信 ID 指定目标；到期自动恢复，时长填 `0m` 可提前解除。

上下文由三部分组成：发言者此前最多十条有效文字、全群此前去重后的近期发言，以及按真实收发顺序还原的最近一轮对话（含机器人自己刚发出的回复，以 `assistant` 角色参与，可直接承接上一轮）。最近一轮对话保留 30 分钟内连续的内容，超过 30 分钟没有新消息就视为换话题；前三部分都不混入其他群与控制指令，使用本群所选的熟人损友或俏皮损友语气，艾特目标始终为原发言者的真实ID。机器人成功发出的回复会落库，作为后续对话上下文；原生回显不会重复保存。

提问中出现的已确认人物会以 `people` 一并送入模型，用于“X 是谁”“X 和 Y 是什么关系”这类跨成员身份查询；只有管理员确认建档（含绑定群成员）的人物才会出现，未建档名字不会凭空生成档案。

本群有进行中的成语接龙时（进度来自成员库 `room_states` 表的 `idiom_chain` 状态）：恰好四个汉字、且首字等于当前接字的艾特消息完全交给接龙插件，本插件不回复；其余艾特消息会把接龙的真实进度（当前成语、接字、最近用过的词）作为 `room_game` 一起发给大模型，并要求它不要自己判定接龙、不要编造进度。没有进行中的接龙时不注入任何进度，也不提接龙。

显示名字优先使用该成员的本群绑定，未绑定时使用缓存中取得的微信名。功能需要成员记录、有效的模型配置和启用的 `mention_chat` 插件。

未绑定者会收到低频绑定提示。管理员重置上下文、修订相关知识或连接结束时会取消待发旧回复；正常跨天不取消。

群友可发 `/音色` 查看当前音色和自称。管理员可发 `/音色 名称` 切换，设置重启后保留。默认用星瞳，自称 A姐；切到男声音色时自称 A哥。

`/语音 原文` 无需艾特，按当前音色直接朗读。普通成员的语音发送结束后由 Jev 判断已经成功发送的内容；明显越界时，暂停本群所有普通成员的 `/语音` 一小时，期限重启保留，到期自动恢复。管理员免判断、不会触发暂停，暂停期间也可使用。普通互损、粗口、亲属口头禅及含蓄黄梗放行；明确恶意攻击、现实威胁、骚扰、露骨色情、仇恨或隐私泄露触发暂停。判断失败不暂停，普通聊天语音不受影响。

`/语音回复` 查看本群固定语音成员。管理员用 `/语音回复 <@群友|M序号|昵称|微信ID> [开启|关闭]` 设置，省略动作表示开启。按群及真实账号保存，重启保留；聊天、追问、工具回答、补课和冷处理的实际回复都使用语音，长回答分成每段最多 80 字，群指令回执仍用文字。合成失败只回退未发送正文，发送结果不明时不补发。

未指定固定语音的普通短闲聊以 50% 概率尝试语音，同一群自动尝试间隔至少 5 分钟；明确要语音时跳过概率与冷却。主动发言频率保持原配置。

聊天回复按成员排队，最多四位成员同时处理；判断、模型生成、联网和看图均不占收消息的线程，同一人的提问保持顺序。语音共用单个合成进程，微信提交仍串行。

搜索证据不支持答复时，先重写，仍不支持则生成针对缺口的查询并补查一次。图片澄清、引用缺失、搜索失败和补查后的信息缺口都交给聊天模型组织回复；模型失败仅记录日志，不发固定聊天兜底。
