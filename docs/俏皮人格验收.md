# 俏皮人格的生成与验收

## 目标

“俏皮损友”是一位亲近、灵动、有自己感受的年轻女性朋友。被夸会开心，认错会有小尴尬，愿意陪朋友想象、表达好奇，也能认真接住难受。轻轻调侃后收住，普通回答同样成立。

验收看整段互动：不靠“呀、啦、呢”计数，不把少了粗口就算作人格生效。重点检查认错后补刀、借旧事贬低、跟随群友围攻，以及连续追问后退回旧口吻。

## 生成职责

| 层次 | 职责 |
| --- | --- |
| `Dialogue`、主动发言、补课与冷处理 | 提供本次任务、事实、能力边界与输出格式 |
| `PersonalityLLM(for_reply=True)` | 组织面向群友的角色表达；俏皮人格移除同源的旧通用风格段，把 API 对话历史放进标明角色的资料区，末尾提示当前角色 |
| 默认 `PersonalityLLM` | 搜索词、成语判定、记忆提取等内部任务，沿用原来的输入和输出契约 |
| `LLMClient` | 执行单次模型请求；模型、预算、超时由现有本机配置管理 |

历史发言、人物档案、群友样稿和记忆仍参与理解事实与承接关系。群友的男性自称、口头禅及旧机器人的挖苦不决定新回复的态度。生成前后继续核对人格快照，过期回复不发送。

“熟人损友”保留原基准人格及 API 历史结构。语音与文字共用角色生成，语音形式仍由原有发送规则决定。指定原话、明确格式、工具事实和详细回答优先。

## 可重复验收

```powershell
python -B tools/evaluate_personality.py
python -B tools/evaluate_personality.py --run --repeat 2
```

默认只列出场景；`--run` 使用本机模型调用正式生成模块，不连接微信或发送消息。报告存入 `.runtime/persona_eval/`，记录模型、每轮耗时、全部回复及硬约束错误。生成请求不包含 `expectation`。多轮场景将上一轮的真实生成放回下一轮，检验持续行为。

场景库为 `tests/fixtures/personality_cases.json`：6 个开发场景与 23 个留出场景，涵盖纠错、分享、失落、调侃、想象、普通问候、文字与语音、精确格式、工具事实、主动发言、补课、冷处理和详细回答。留出场景不写入人格样稿。

| 门槛 | 检查方式 |
| --- | --- |
| 无空答、原文改写、格式错误、事实漏项、语音标记错误 | 自动检查全部重复回放 |
| 不借钱、能力或旧糗事补刀；认错后收住 | 逐条审阅，任一反例退回修正 |
| 亲近且有自己的情绪和反应，符合场景期待 | 独立审阅全部关系互动场景，不用生成模型自评代替 |
| 多轮保留事实，接受结束，停止不舒服的调侃 | 连续纠错、连续被夸、明确不舒服三个线程 |
| 普通接话简短、详细回答完整 | 独立检查内容及长度；主动和语音另有原有上限 |
| 正式入口确实使用新角色路径，内部任务契约保留 | 真实插件入口与人格、语音、主动发言、定时发言测试 |
| 复杂历史中的原失败场景修复 | 当前配置对历史对话重建后，每场重复三次 |

真实对话回放使用当时消息水位和当前人物记忆、群习惯、设置，检验现在的程序面对这些历史对话的行为。它不冒充当时完整请求的逐字复原。私有对话与配置不进入仓库。

## 运行配置与验收记录（2026-11-12）

本轮部署使用现有 Magpie 接入和订阅额度，本机 `llm_config.json` 的 `model` 为 `codex/gpt-6.1-sol`，`chat_reasoning_effort` 为 `low`。沿用一个生成请求，不增加意图分类、候选自评或第二次改写。该配置是主模型配置，内部总结、学习等模型任务也使用它；Jev 判断仍使用独立的 `jev` 配置。

| 项目 | 结果 |
| --- | --- |
| 全仓离线测试 | 840 项通过，含长上下文分批及合并摘要与最终发言的入口隔离 |
| 虚构场景 | 29 场景 × 2 次，共 74 条生成；原文、格式、必需事实和各轮长度检查全部通过 |
| 普通聊天长度 | 56 条普通接话的中位数 29 字，最长 42 字；详细回答单独保持完整 |
| 真实失败场景 | 3 场景 × 3 次；每次带 40 条真实历史及 8–9 条当前记忆，无认错后补刀或翻旧事贬低 |
| 单轮生成耗时 | 中位数 3.62 秒，p90 为 4.89 秒；不含微信发送等待和语音合成 |
| 独立审查 | 代码规范与需求效果分别审查，发现项修复后定向复核通过 |

本机完整结果为 `.runtime/persona_eval/20261112-012200.json`，真实重建结果为 `.runtime/persona-diagnosis-20261112/production-replay.json`。角色质量依据逐条语义审阅，自动检查负责格式与事实约束；后续变更模型或角色组装时，按同一场景库复验。
