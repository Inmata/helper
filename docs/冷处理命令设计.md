# 群聊冷处理命令

群友反复艾特或引用机器人挑衅时，维护者可以给机器人设一段冷处理时间。机器人平时少接话，偶尔用一句阴阳怪气的短句回击。

## 命令

- `/冷处理 M12 30m`、`/冷处理 @群友 2h`：指定当前群的一位成员。目标支持 `/成员` 里的编号、微信 ID 和微信真艾特。时长是整数加 `m`（分钟）或 `h`（小时）。
- 只有配置的维护者能在群内使用。再次设置会从执行时重新计时；`/冷处理 @群友 0m` 提前解除。
- 状态按机器人账号、群和目标成员区分，复用现有群状态存储。重启后继续按原到期时间计算。

## 回复方式

全程静默最安静，但缺少机器人回嘴的效果；逐条让模型回击会给对方持续互动的机会。采用限频短句：目标成员设置后第一次触发艾特回复就回一句，之后每隔至少 10 分钟可再回一句。中间的艾特直接跳过，到期自动走原回复流程。

短句轮换，发送时只艾特发言者。例如：

- “这话题挺耐聊，我就不续杯了。”
- “收到，今天的演出我就看到这儿。”
- “你这段循环播放，我这边就不续费了。”

普通发言、其他成员和其他群照常处理。冷处理只接管艾特聊天，不改变游戏和其他命令。被接管的艾特不进入模型、看图或联网；设置前已经在生成的普通回复，在发送时也受当前冷处理状态约束。

## 验收与规范

用离线测试覆盖维护者鉴权、真艾特和编号定位、群间隔离、首次回击与间隔限制、解除和到期恢复，以及在途普通回复的发送检查。交付时更新艾特回复规范、维护者帮助、使用手册和项目更新公告。
