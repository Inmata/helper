# 微信群里的连续接话

2026-11-10 · 首版设计。

让机器人知道自己在跟谁聊、接的是哪一句，以及这句什么时候值得说。群友可以顺着上一轮追问；碰到正在成形的群梗，机器人可以晚一点接。管理员选人格口吻，聊天现场决定怎么接话。

## 取舍

| 方案 | 取舍 |
| --- | --- |
| 只把主动发言理由传给生成 | 改动最小，仍解决不了分段补充和没艾特的追问。 |
| **共用一轮对话，并给主动发言标明目标** | 推荐。既能把连续消息接起来，也能避免主动和艾特两边各答一次。复用现有成员历史、Jev、回复生成、慢队列和发送。 |
| 每个群维护完整的多话题状态或多个角色 | 玩法多，首版难以分辨是接话变好，还是单纯发得更多。只保留这条作为后续方向。 |

现有代码已经统一标记群友和机器人发言，也能识别引用机器人。差距在两处：艾特回复固定在当时那条消息的快照；主动发言做完「点名、补答、接梗」判断后，只把聊天正文交给生成。参照 [MaiBot 的新消息接入](https://docs.maibot.chat/faq/chat-and-reply) 和 [HUMA 的中断后重判](https://arxiv.org/abs/2511.17315)，先把来源和意图接到现有回复链路上。

## 第一版行为

1. **把补充算进同一轮。** 真艾特和引用机器人仍明确触发。完整问题直接开始回复；只发素材、问题明显还没写完时，最多等约 5 秒收同一人的一句补充。已开始处理时，发送前若收到同一人的相关条件更新，按新条件重判一次；其他人的消息不会混进提问。处理中补一个空艾特，只合并到已接住的追问。重判后条件再变，取消尚未发送的旧结果，用最新条件另排一轮；若已有正文或语音发出，新内容另起一轮，不重发已发内容。
2. **接住没艾特的自然追问。** 定向回复从现有发送接口报告成功起，给这位群友一个 30 秒短窗，不额外等待群内回显。消息明确在延续机器人刚才的答复时，可连续接两轮；纯感叹、向别的群友发问、明显换题时按普通群聊处理。只在有这个短窗时调用现有 Jev 作一次快判；新艾特、引用原消息照旧生效。引用机器人的语音仍按原消息读取保存的原文。
3. **主动开口前选准原话和动作。** 规划交给生成的内容至少有目标消息、发言意图（回应点名、补答、接梗）和当轮相关上下文。最高发言选项用作意图线索，不当作发言命令；已被回答、接错对象或已换题就不发。首版仍用现有文字和表情包，发送层无需新增微信原生引用能力。
4. **可以留一个梗等后续。** 第一次「五分钟到」可以直接跳过；第二次若形成明显的反复线索，可保留原话作为接梗候选。只有新的同话题群友消息到达，才在随后的正常停顿中再判；处于观望区间时，确认新消息接着这个梗也可以进入生成。单独的定时或静默复判不触发旧梗。每群最多留一个候选，30 分钟后过期，换题时不使用。使用现有主动发言预算。

## 工程落点

- 在 `conversation/` 归属一份短时接话状态，以连接、群、发言者和原消息编号定位；进程内保存即可。入口只观察已入库的消息，不在收消息线程上调用模型。
- 艾特插件负责产生定向回复，主动插件通过同一份状态知道哪条已被接住。未通过续接判定的消息仍可参与正常的群聊判断。发送成功才延续短窗；已有命令、冷处理、接龙优先规则保持有效。
- 复用现有工具和语音慢队列、主动预算、过时消息检查与发送守卫。直接追问属于定向回复；主动补答与接梗共用原有主动配额。保持其他成员的普通回复可继续处理。
- 只记录会改变判断的调试信息：来源、选中的目标消息编号、动作和发送结果。人格预设、音色、历史库结构及发言频率不在本版调整范围内。

## 回放与验收

用原群脱敏改写的三段记录和六个对照做了不发送的 Jev 回放（本机样本 `.runtime/research-tools/continuous-turn-replay-20261110.json`）。预设动作一致 8/9，单次判断中位 0.30 秒：四秒后补问、语音后追问和补空艾特均识别正确；「同一人转头问别人」「问题已有人回答」「已经换题」均选择沉默。唯一分歧是第一次说「五分钟到」时直接沉默，效果同样合适，因此设计允许首句直接略过。这组结果只覆盖动作判断，整条发送链路留到实现后验证。

实现后按消息到达顺序回放原群的脱敏片段：同一人的补充只产生一次答复；自然追问能少补一次艾特；对别人的问题不抢答；旧梗在新话题中不冒出来；完整艾特无需额外等待。原群验收观察群友自然发出的艾特和后续追问，命令行检查收发日志与回执；没有合适的自然样本时，只需群友补一组。全程不操作微信窗口，通过后按现有流程重启、发公告、提交推送。

首版回执：真实艾特的文字与语音照常发出。另将一组补充和追问回放到临时库，通过原群的实际微信连接发送，收到两条回执：补条件后只回「北门」（5.45 秒），不艾特追问回「南门」（6.22 秒）。
