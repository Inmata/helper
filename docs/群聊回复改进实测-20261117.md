# 群聊回复改进实测

日期：2026-11-17。所有操作通过命令行完成。

## 已交付行为

- 人物上下文覆盖艾特、追问、自然接话和定时候选。按实际成员读取近期原话，包含生图请求；生成与核对共用这份材料。
- 普通/详细回复分别共用90/120秒预算，30秒一次进度；排队、网络调用、重规划和语音等待不刷新时限。到期由一个收口者发送已核对正文或状态，阻止迟到补发。
- 文字偏好持久保存，发送时执行。档案确认保留5分钟，无关插话不直接消耗；新疑问之后的含糊肯定不误认成确认。
- 已发送图片以文件摘要登记，重启可恢复明确引用。看图与改图共享解析；旧产物仅在真实引用来自本账号且摘要相同时回填。
- 生图进度读取执行器，已取得远端编号的重试继续查询原任务。图片提交未确认时停止补发。
- 机器人本机配置固定 `codex/gpt-6.1-terra`；共享 `group/bot` 保持其他应用的原配置。配置、账号和完整群聊未进入 Git。

## 发现与验证

| 项目 | 证据和结果 |
|---|---|
| 人物材料缺口 | 原始记录保存了多条 `/生图` 描述，普通有效文本读取会过滤控制命令。人物定向读取显式保留这些请求后，源消息进入生成和核对输入 |
| 人物回放 | 原失败样本 #36246、#36248 均重放，回答能够归纳具体偏好和群内互动；最终两条分别约4.4秒、5.3秒 |
| 问法覆盖 | 同一真实消息截面的32条回放，含原问题及近况、推荐、比较、接话等变体。32条均提供具体相关内容；完整生成链路耗时中位数6.30秒，p90为8.19秒，最大11.60秒，不含微信真实传输时间 |
| 路由核对 | 当前共享组实际路由为Gemini；同样本GPT回放更快且更集中。仅固定本机器人配置，不修改共享组 |
| 英文控制文字 | 上游曾把过滤提示和重试指令混进正文，已增加入口拒绝与回归测试，群里不发送该控制文本 |
| 真实引用看图 | 用户在群里引用机器人生成图，实际引用摘要与已发送文件一致；日志显示 `vision=ok`，后续正确描述雪地柴犬、棉大衣和铁锅 |
| 真实引用编辑 | 从该引用定位的同一文件发起Magpie编辑，要求保留主体、帽子和棉大衣，换成春日农家院。生成成功；独立识图确认服饰保留，背景出现桃花、黄花和绿植 |
| 微信发送回声 | 命令行测试没有收到自己发图的同步回声。当前定位采用已实测的文件摘要；不依赖猜测消息编号或内存偏移 |

人物回放中的严格事实自动评分有13/32达到0.7，其余涉及主观归纳、推荐创意和任务时序等边界，不计为严格自动通过。版本没有宣称32条的所有事实均已得到自动认证；程序继续保留依据核对和一次修订。原始输入、候选及评分保存在本地私有回放资料中。
